# Tank Battle with Enemy AI

C++17 と raylib を使用して開発した、2D戦車対戦ゲームです。Windows デスクトップ環境に加え、Emscripten を用いて WebAssembly にコンパイルし、Webブラウザ上でも動作するようにしました。

敵キャラクターの行動制御には **有限状態機械（FSM）**、障害物を考慮した経路探索には **A*アルゴリズム** を採用しています。

## 🎮 ゲーム概要

プレイヤーは戦車を操作し、マップ上の障害物を利用しながら敵戦車と戦います。

敵戦車はプレイヤーとの距離や障害物の配置に応じて、巡回・追跡・攻撃の行動を切り替えます。

また、AIの挙動を確認できるデバッグ表示機能を実装しています。

## 🧠 技術的な特徴

### 1. 有限状態機械（FSM）による敵AI

敵キャラクターの行動管理に有限状態機械（Finite State Machine）を使用しています。

敵は周囲の状況に応じて、以下の3つの状態を切り替えます。

- **Patrol（巡回）**：指定された経路に沿って移動
- **Chase（追跡）**：プレイヤーを検知し、経路探索を用いて追跡
- **Attack（攻撃）**：射程内かつ攻撃可能な状況で射撃

状態ごとに処理を分離することで、行動制御の見通しと拡張性を意識しました。

### 2. A*アルゴリズムによる経路探索

グリッド形式のマップに対して A*アルゴリズムを実装しています。

敵キャラクターは障害物の配置を考慮し、プレイヤーの位置までの経路を探索します。

単純にプレイヤーの方向へ移動するのではなく、壁を迂回した追跡行動を実現しています。

### 3. AIデバッグ表示

F1キーでAIデバッグ表示を切り替えることができます。

敵の現在の行動状態や経路探索の結果を可視化することで、AIの動作確認や問題点の把握を行いやすくしています。

### 4. クラス設計と機能分離

ゲームロジックを複数のクラスに分割し、それぞれの役割を明確にしています。

| クラス | 主な役割 |
|---|---|
| `Game` | ゲームループ、入力処理、勝敗判定、描画 |
| `Tank` | プレイヤーと敵戦車の移動、照準、射撃 |
| `EnemyAI` | FSMによる敵キャラクターの行動制御 |
| `Pathfinding` | A*アルゴリズムによる経路探索 |
| `TileMap` | マップ管理、衝突判定、視線判定 |
| `Projectile` | 弾の移動と管理 |
| `GridPos` | グリッド座標の管理 |

これにより、ゲームループと各機能の処理を分離し、保守性や機能追加のしやすさを意識した構成としています。

### 5. WebAssemblyへの移植

Emscripten を使用し、C++ で実装したゲームを WebAssembly にコンパイルしています。

Windows版とWebブラウザ版で共通のゲームロジックを利用し、プラットフォームごとに必要な処理のみを切り替える構成にしています。

また、HTMLテンプレートをカスタマイズし、ブラウザ上でプレイしやすい画面構成にしました。

## 💻 ビルド方法

### Windows デスクトップ版

必要環境：

- C++17 対応コンパイラ
- CMake
- Git
- raylib のビルドに必要な開発環境

CMake の設定により、初回ビルド時に raylib 5.5 を取得します。

```bash
cmake -S . -B build
cmake --build build --config Release
```

Visual Studio の場合、実行ファイルは通常 `build/Release/TankBattleAI.exe` に生成されます。

### WebAssembly版

Emscripten SDK、CMake、Ninja が使用可能な環境で以下を実行します。

```bash
emcmake cmake -S . -B build_web -G Ninja
cmake --build build_web
```

生成されたWeb版は、ローカルHTTPサーバーから確認できます。

```bash
python -m http.server 8000 -d build_web
```

ブラウザで以下にアクセスします。

`http://localhost:8000/TankBattleAI.html`
